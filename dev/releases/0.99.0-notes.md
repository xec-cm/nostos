# nostos 0.99.0 — experimental MVP

Release-note draft for maintainer publication. No release or tag is created by
this file.

nostos now provides a complete descriptive workflow for microbiome return
to an explicit personal baseline in a TreeSummarizedExperiment:

- `setup_recovery()` registers named analyses, episodes, events and time.
- `add_reference()` attaches profiles from explicitly selected baseline samples.
- `add_deviation()` records Bray--Curtis deviations from fixed episode profiles.
- `add_recovery()` records observed return, confirmation, rebound and coverage
  under a stated threshold, persistence, maximum-gap and horizon rule.
- `validate_recovery()` diagnoses current dependencies without rewriting history.
- `recovery_results()` extracts sample and episode tables with validation context.
- `plot_recovery()` displays observations and saved evidence as a ggplot.

The README and vignette use bundled synthetic data and independently checkable
outcomes. Filtering preserves historical results; missing evidence and changed
inputs remain explicit. Optional tidy interoperability is limited to the tested
operations and versions in the [assessment](https://github.com/xec-cm/nostos/blob/devel/dev/tidy-interoperability.md).

## Requirements and installation

Requires R >= 4.6.0 and the declared CRAN/Bioconductor dependencies. The core
workflow does not require a tidy adapter. Installation from `devel` remains
available as documented in the README.

**After the maintainer publishes the tag**, an installation pinned to this
release will be:

```r
remotes::install_github("xec-cm/nostos", ref = "v0.99.0")
```

For an already downloaded checked source archive with dependencies installed:

```r
install.packages("nostos_0.99.0.tar.gz", repos = NULL, type = "source")
```

## Limits

The API is experimental. One baseline cannot establish stability, and similarity
to baseline does not establish health, functional restoration or uninterrupted
recovery between visits. No automatic threshold calibration, statistical fitting,
group comparisons or recovery-time uncertainty estimator is included.

Historical records are not automatically recomputed after filtering. Table and
plot outputs are snapshots; extract again from the TSE for current diagnostics.
Selected sparse/delayed blocks can be realized in memory. Optional tidy mutation
can lose annotation metadata in the tested adapter; consult its bounded scope.

Version 0.99.0 replaces the unpublished 0.2.0 target and prepares an initial
Bioconductor submission candidate. GitHub publication does not constitute
Bioconductor submission or acceptance.
The candidate's exact source identity, check evidence, coverage and outstanding
Bioconductor work are recorded in [release preparation](https://github.com/xec-cm/nostos/blob/devel/dev/releases/0.99.0.md) and the
[readiness assessment](https://github.com/xec-cm/nostos/blob/devel/dev/bioconductor-readiness.md).
